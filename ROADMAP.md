# Roadmap

This is what is coming next for Voxprint AI Enlarge. The current install is `v0.2.0-rc.4`.

## Next version

* The command line will be able to do everything the window does: a folder and its subfolders, one event per image, and cancel and resume of a batch.
* The app will pick a model from the graphics memory it can actually use, and hide options the card cannot run.
* Model downloads will try more than one mirror and move to the next mirror when a download fails.
* Graphics memory, system memory, and disk will be used together so bigger and better models fit on 16 GB and 24 GB cards.

## Later

* More upscaling models, including an optional face-restore model.
* A clearer before-and-after export, and starting a batch from the file manager.
